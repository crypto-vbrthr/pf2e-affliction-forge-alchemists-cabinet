# Changelog

## 0.1.0

- Initial Alchemist's Cabinet library release.
- Added 32 original staged alchemical afflictions from levels 0–20.
- Added 12 weapon injury poisons for the existing coating/charge workflow.
- Added laboratory diseases, aerosols, ingestible toxins, contact agents, injections, and mutagenic failures.
- Added semantic Creature Forge tags using contract 1.0.0.
- Added DE/EN localization.
- Added persistent damage, virulent progression, concentration gates, speech blocking, healing restrictions, condition locks, and a level-20 death effect.
- Added Foundry 14-safe managed compendium synchronization.
- Added schema, localization, semantic-tag, portability, injury-poison, advanced-mechanics, and runtime smoke tests.
